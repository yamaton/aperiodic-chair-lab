# 配置アニメーションの独立レビュー

2026-09-19。ユーザーの依頼により、実装担当とは別の2つのAIエージェントが
未コミットの配置アニメーション変更を読み取り専用でレビューした。
確認範囲内では、再現できる製品の不具合は報告されなかった。
アプリケーションのコードは、このレビューによって変更していない。

対象の単独HTMLのSHA-256:
`8c8dfd06a7f586a28c19a7b92f8a9c95afc8ac07debfde4e19724da888b4e4be`

## 担当と確認範囲

| 担当 | 確認した内容 | 結果 |
|---|---|---|
| `review_state` | 2枚目の面選択、仮置き変更、接着ボタンの到着待ち、履歴、取消・再開始、内部閲覧、動きを減らす設定 | 不具合の指摘なし |
| `review_animation` | 剛体回転の補間、重心、描画・面の選択、フレーム処理、デモの停止・再開・一手送り、単独HTMLへの組み込み | 不具合の指摘なし。テスト改善の提案1件 |

両担当は既存の配置アニメーション検証を別途実行し、576通りの回転間の補間と
Firefoxの動作確認が通ることを確認した。検証記録は一時ファイルへ出力し、
リポジトリの既存記録を上書きしなかった。

状態管理担当は追加で、親を組み立てて次の階層へ進み、動作途中に内部を開いて戻る操作を確認した。
未確定の配置が保持され、古い動きが消え、接着ボタンが再び使えることを確認した。
また、30回の取りつけ先・候補の連続変更について、変更時の表示位置・向きの連続性と、
最後の選択位置への到着を確認した。JavaScriptエラーや外部通信は発生しなかった。

描画担当は、格子上の姿勢に到着する前に回転を切り替える追加の10,000回の計算を実行した。
到着先の回転を `rotations[(i * 17 + 7) % 24]`、途中の時点を
`((i * 17) % 103) / 103` とする決定的な検査で、開始姿勢の連続性と
回転行列の直交性を確認した。最大数値誤差は約 `2.23e-15`。
既存のデモ検証も実行し、自動再生・停止・一手送り・接着・再実行・プレイヤー状態保持、
日英表示、動きを減らす設定、390px幅と667×375・750×600・320×568で通過した。

主担当は、単独HTMLが現在の生成元と一致すること、公開用の生成経路にも
`motion.js` が埋め込まれること、Pagesのワークフローが追加ファイルを監視することを確認した。

## テスト改善

デモの一時停止検証には、停止後の姿勢が変わらないことの確認があった。
描画担当から「停止操作の前に動作が終わっている場合にも通るため、実際に途中の動きを
停止したことも確認するとよい」と提案があった。観測されたアプリの不具合ではない。

`verify-demo.cjs` に、停止直後のアニメーション段階が空でないことの確認を追加した。
これにより、動作途中を止めたことと、その姿勢が停止中に変わらないことの両方を検査する。
再確認のコマンドと記録:

```sh
node docs/assembly/verify-demo.cjs
```

追加後の再実行も通過し、[デモ検証記録](../assembly_demo_verification.json)に結果を保存した。
既存の回転・操作の再現手順は[実装ノート](README.md)を参照。

## 限界

独立したAIによるコードレビューと、範囲を限定した自動検査である。
Firefoxのヘッドレス実行・画面幅の変更・動きを減らす設定のエミュレーションを使用した。
実機のタッチ操作、他のブラウザーエンジン、人間の初見プレイヤーによる試用は未確認。
周囲の物体と衝突しない移動経路の検証や、数学的構成の証明審査は対象外。
このレビューに伴うコミット・公開は行っていない。
