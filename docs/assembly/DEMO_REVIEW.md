# 操作デモの独立レビュー

2026-09-17。ユーザーの依頼により、独立した2つのAIエージェントが読み取り専用でレビューした。
一方は初見プレイヤーのUX、もう一方は状態保持と操作の境界条件を担当した。
主担当も別途実装と画面サイズ変更を確認した。人間の初見プレイヤーによる試用や数学的証明のレビューではない。

## 指摘と対応

| 優先度 | 指摘・再現 | 対応 |
|---|---|---|
| P2 | Firefoxの667×375と750×600で、デモを停止して「次の操作」を2回押すと部品面をクリックできず停止する。SVG面への`scrollIntoView()`後も面中心が表示枠の外に残った。高さ不足時には終了・再生操作も画面外になった。 | SVG面の実測した中心へ、デモ文書内を明示的にスクロールする。ダイアログを画面高に収め、低い横画面では実演を左、説明と操作を右に配置する。 |
| P3 | 750×600の比較段階で、強調枠の260px幅制限により、両カードの間の空白だけを囲んだ。 | 比較段階では比較欄の幅全体を囲む。両カードが強調範囲に入ることを検証に追加する。 |

P2の修正後、UX担当が667×375・750×600・390×844で全5操作の完了と、
説明・終了・再生操作が画面内に収まることを独立に確認した。
P3も750×600で限定再レビューし、強調枠が左右両カードを完全に囲むことを
実測と画面で確認した。UX担当の指摘2件はいずれも解消を確認済み。

状態保持担当は、保存領域が使えない場合の英語選択の引き継ぎ、読み込み途中を含む
12回の急速な開閉、6回の再実行・停止、未確定部品とRedoの保持を独立に確認し、
これらについて追加の不具合は報告しなかった。
主担当は320×568・844×390・1024×600と、各操作間での1280／390幅切り替えも確認した。
