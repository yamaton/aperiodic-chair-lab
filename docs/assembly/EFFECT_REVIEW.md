# 接触エフェクトの独立レビュー

2026-09-19。ユーザーの依頼により、実装担当とは別の2つのAIエージェントが、
`f5e32fe` 以後の未コミット変更を読み取り専用でレビューした。
対象は模様不一致の赤い実線、矢印だけが不一致の場合の同じ赤の破線、
および仮置きの回転に伴う接触表示の更新。
確認した範囲では、再現できる製品の不具合は報告されなかった。
このレビューによるアプリケーションコードの変更はない。

対象の単独HTMLのSHA-256:
`fce6cf71f9bf4fc1e65e1e6d87279d56e1555e9aada82711f54b3f7895ff0486`

## 描画と比較窓

`review_effect_rendering` がコードと実画面を確認し、独自のFirefox検証で
初期24ターゲット面について523候補、1,236接触比較、1,046視点を確認した。
候補は模様の組み合わせ、矢印の適否、重なり、他面の模様不一致、接触数が
異なるものを代表として選んだ。全候補の網羅検証ではない。

各候補を通常と約180度反対のカメラから描画し、可視接触面の判定から期待される
赤い破線・実線と強調矢印の本数を、Canvasの実際の描画呼び出しと突き合わせた。
各接触へ比較窓を切り替え、左右両カードの赤と線種、接着可否も判定結果と一致した。
ページエラーは発生しなかった。

矢印不一致面の下地に細い赤実線がある点は、両担当が検討した。
模様不一致と矢印不一致が併存する候補の画像では、赤の実線と破線を区別でき、
懸念した破線の実線化は再現しなかったため、不具合の指摘とはしなかった。

## 状態管理

`review_effect_state` がコードを確認し、独自のFirefox検証で次を確認した。
再現できる不具合の指摘はなく、検証は終了コード0、ページエラー0で通過した。

- 24回の回転と途中での操作変更後に、最終配置・比較表示・接着可否が判定結果と一致する。
- 動作途中の言語変更、取消、Undo/Redo後に古い表示が残らない。
- 動きを減らす設定の変更と非表示イベントで、最終配置と表示が更新される。
- 親への昇格後、不適合配置への移動中に内部閲覧へ入ると警告が消える。
  900ms後も古い動きは復活せず、組立へ戻ると正しい不適合表示に戻る。

非表示の確認には `document.hidden` と `visibilitychange` の模擬実行を使った。
実OSでのタブ切り替えを試した結果ではない。

## 生成物と既存検証

主担当は、単独HTMLと生成元の一致、および6つの検証成功記録のHTMLハッシュが
上記と一致することを確認した。公開用ビルドも同じ生成関数を使う。
独立検証のスクリプトと出力は一時ファイルを使い、既存検証記録は上書きしていない。

既存の再検証手順と記録は [実装ノート](README.md) を参照。

## 限界

独立したAIによるコードレビューと、範囲を限定したヘッドレスFirefox検証である。
実機のタッチ操作、他のブラウザーエンジン、人間の初見プレイヤーによる試用は未確認。
数学的構成の証明審査や、物理的に衝突しない組立経路の確認は対象外。

## 追補: 適合する全接触面の緑表示

2026-09-19。選択外を含むすべての適合接触面に緑の枠と面色を加えた変更について、
ユーザーの依頼で別の2つのAIエージェントが独立レビューを行った。
この追補の対象は `16e57d8` 以後の変更で、上記の初回レビューとは区別する。

対象の単独HTMLのSHA-256:
`13d5d98e4f0897ab87f39ad51a007260d2efa20d3d99b7edae68356e98f1eb4e`

`review_valid_rendering` は、階層0と親昇格後の階層1で、複数の適合面、
適合・不適合の混在、内部の重なりがある代表候補を各4視点から検証した。
7段階の案内接着、親昇格、内部閲覧と復帰も含め、40フレーム・121本の接触枠について、
投影中心座標・色・線種が判定対象の接触面と一致した。
赤が緑の後に描画されることを確認し、親階層での赤緑混在も画像で確認した。
確認範囲内で再現できる描画不具合は報告されなかった。

`review_valid_state` は、2階層の組立と14段階の適合接触面数、回転後の赤・緑、
接着とUndo/Redo、親の表示切替と内部閲覧を含む151項目を独自検証した。
動作中のエフェクト抑制、動きを減らす設定・非表示イベントでの完了と表示復帰も通過し、
ページエラーは発生しなかった。確認範囲内で再現できる状態管理の不具合は報告されなかった。

主担当は生成元と単独HTMLの一致、および6つの検証成功記録が今回のHTMLと一致することを確認した。
レビューによるアプリケーションコードの変更はない。独自検証は一時ファイルを使い、
既存検証記録は上書きしていない。実機モバイル、Firefox以外、全候補の網羅検証は対象外。
