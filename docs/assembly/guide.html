操作チュートリアル

まずは1個、接着してみましょう。予備知識はいりません。

1. 接着済みの組立で、面を選ぶ

接着済みの組立が対象物、オレンジが取り付ける部品です。組立の面をクリックすると、部品の取り付け候補が現れます。

接着済みA →クリック
＋
取り付け中?

面が見えないときは、3D表示をドラッグして見回します。接着済みの部品は外れません。

2. 取り付ける部品の面を選ぶ

「取り付ける部品の面をクリック」の小窓で、使いたい面をクリックします。組立の3D表示にあるオレンジの部品からも選べます。

見回す↶ ◇ ↷
→
面を選ぶA ↑

小窓のドラッグや視点ボタンは、見る方向だけを変えます。面を選ぶと取り付け候補が変わります。番号を覚える必要はありません。

3. 比較窓で、模様と矢印を合わせる

「接触面を比べる」は、両面を同じ向きから見た図です。左の矢印を右向きとして、右の矢印を下の例に合わせます。

A →＋A ↑✓
B →＋C ←✓
C →＋B ←✓

比較窓の下の「この図で左へ90°」「この図で右へ90°」で、部品の向きを変えられます。

接着できないときは、別の面や向きも試しましょう。重なりがなく、触れるすべての面が合う必要があります。「なぜ？」で理由を確認できます。

4. 接着して、次の1個へ

条件がそろうと「接着する」を押せます。押すまでは仮置きです。接着した部品は組立と一体になります。

接着する→次の1個

やり直したいときは「元に戻す」。接着直前の部品に戻せます。「親を一つ作る」では、「ヒントを見る」を押すと、場所・矢印・具体的な候補の順に案内します。

1個できたら、次は？

「親を一つ作る」では、ヒントを使って8個の組立を目指せます。決まった形ができたら「親にまとめる」、続いて「この親で次を組む」で、ひと回り大きな組立に進めます。「自由に組む」では、別の組み合わせも試せます。
