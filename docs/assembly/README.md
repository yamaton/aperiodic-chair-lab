# 組立教材の試作

[単独で開ける試作HTML](../assembly.html)。ブラウザーでファイルを開くと、通信なしで操作できる。
画面上部の「表示言語 / Language」で日本語・英語・中国語（簡体字）を切り替えられる。
公開用ビルドの `assembly/` にも組み込まれているが、この更新はまだ公開していない。
初回はブラウザーの言語設定を参照し、選んだ言語は保存可能な場合に次回も使用する。
組立中や内部の閲覧中でも切り替えられ、配置・選択した面・Undo/Redoは維持する。
画面上部の「操作チュートリアル / How to play」は、選択中の言語で読む4段階の操作ガイド。
面の選択、部品の面の選択、模様と矢印の比較、最初の接着を図付きで案内する。
ガイドはページ内で開き、閉じても配置・取り付け候補・履歴を変えない。
「▶ 実際の操作を見る / Watch the actions」で、実画面のカーソル実演を再生できる。
対象物の面選択、部品の面選択、比較、90度回転、接着を約16秒で示す。
一時停止・次の操作・もう一度に対応し、閉じると操作ガイドに戻る。
実演は同じ描画・判定・操作処理を使う独立した画面で行い、プレイヤーの組立や視点を変えない。
タブを離れると一時停止する。動きを減らす設定ではカーソルの移動アニメーションを省く。
親の組立への進み方は最後の「1個できたら、次は？」に折りたたむ。
既存の学部生向け英文解説は、ページ末尾の「背景の数学を読む」から開く。

最初は「親を一つ作る」で、対象物の面を選び、取り付け中の部品の面をクリックして接着する。
「取り付けたい面を選ぶ」では接着済みの群がゆっくり明滅し、カーソルが乗ると面だけを強調する。
接着済み側の面をクリックすると、取り付け中の部品を移動させず「向きを合わせて接着する」へ進み、発光だけが取り付け中の部品に移る。
取り付け中側の面は自動選択しない。離れた部品の面を3Dまたは専用窓で選んだ時点で、初めて面を合わせた仮置きにする。
2枚目の面を選ぶと、部品の中心で向きを合わせて回転し（約0.36秒）、仮置き位置へ近づく（約0.3秒）。
すでに仮置き中の部品の面を変える場合や90度回転では、先に接触面から離す（約0.2秒）。
向きが変わらない段階は省略する。模様・矢印の正解は自動選択せず、従来の比較・回転操作を保つ。
接着済み側の面を選び直すと、部品は滑らかに待機位置へ戻り、相手面は未選択になる。
連続操作では途中の表示位置から新しい配置へ動き直す。接着ボタンは到着まで無効になる。
途中の位置・角度は表示だけに使い、判定と履歴には最終配置だけを渡す。
Undo・Redo・取消・再開始では古い動きを破棄する。内部閲覧へ移る場合も動きを終える。
「動きを減らす」設定では位置・向きを即時に切り替える。タブを隠した場合は最終配置へ進める。
操作デモの一時停止は部品の動きも止め、一手送りでは前の動きを完了して次の操作へ進む。
面の選択だけでは接着を確定せず、「接着する」ボタンで確定する。
部品専用窓でも全体の明滅と面のホバー／キーボードフォーカス強調が使える。
OSの「動きを減らす」設定では明滅を静的なハイライトに置き換える。
仮置き中、模様と矢印の両方が適合するすべての接触面には、緑の実線枠と薄い緑の面色を重ねる。
選択していない面も対象とし、取り付け元・先のどちらから見ても表示する。
適合と不適合が混在する場合は面ごとに緑と赤を使い分け、重なる枠は赤を優先する。
緑はその接触面の適合を表し、別の面の不適合や物体の重なりがあれば接着できない。
仮置き中、A/A・B/Cの模様は適合していて矢印だけが違う接触面には、
赤の破線枠・薄い面色・太い矢印を重ねる。選択・ホバー中もこの表示を保つ。
接触面の強調は手前の部品越しにも見えるよう、物体の描画後に重ねる。
比較窓の両面も同じ色と破線枠で強調し、矢印の不一致を色以外でも区別する。
模様自体が不一致の面（B/Aなど）は、3Dと比較窓の両方を赤い実線枠と薄い赤で強調する。
選択・ホバーの緑よりも不適合表示を優先する。赤は両方で共通とし、実線と破線で区別する。
表示は静的で、矢印の実際の向きや接着判定を変更しない。
すべての接触面で模様が合い、矢印だけが不適合の場合も全体の判定文は赤になる。
他の面に模様違いがあれば全体の判定は赤のまま。内部が重なる配置でも面ごとの矢印不一致は表示し、
全体の重なり警告を赤で併記する。重なりがあれば接着はできない。
離脱・回転・接近の途中では接触判定の色と強調を一旦消し、比較窓と判定文に「位置と向きを調整中…」を表示する。
到着時に3Dの面強調・比較図・判定文を同じフレームで更新する。
比較窓の高さを保持して回転ボタンの位置が大きく動くことを防ぐ。
部品の面は組立の3D表示からも、部品だけを表示する専用窓からも選べる。
専用窓をドラッグするか視点ボタンを押すと、隠れた面も探せる。
この視点操作は取り付け位置やUndo/Redoを変えない。接触面での向きは比較窓の90度回転で調整する。
迷ったら「ヒントを見る」を進めると、場所、矢印、具体的な候補の順に表示される。
接着済み側の面を選び直すと古いヒントを消し、ヒントの案内も最初の段階から再開する。
裏側の面は「選択・ヒントの面を見る」で観察できる。
8個が親になったら「親にまとめる」「この親で次を組む」で同じ操作を繰り返せる。
内部の観察では、3Dまたは部品一覧から子を選び、「組立に戻る」で元の作業を再開する。

## 実装した範囲

- 対象物は接着済みの一体の群、操作物は高々1個。接着条件は全共有面の模様・矢印と非重複。
- 対象物と操作物の3D面のクリック選択、操作物だけを見回せる専用窓、比較窓を基準にした90度回転、明示的な接着。
- 面番号の一覧は折りたたんだ補助操作。専用窓の面はキーボードでも選べる。
- 別の接触面の説明中は、取り付け面の比較へ戻ってから回転する。
- Undo/Redo、下書き分岐、追加取消、案内から自由組立への履歴を保持した移行。
- 親の認識、子の境界／外周／親の規則の表示切替、次の階層、内部の閲覧。
- 内部の閲覧中は編集と履歴を休止し、戻ると未確定部品と視点を復元する。
- オフライン表示。キーボードで使えるフォームと視点ボタン。狭い画面では組立を見ながら操作できる配置。

## 再生成と確認

すべてリポジトリのルートから実行する。追加のランタイム依存はない。

```sh
node docs/build-assembly.cjs
node docs/assembly/verify-engine.cjs
node docs/assembly/verify-browser.cjs
node docs/assembly/verify-demo.cjs
node docs/assembly/verify-effects.cjs
node docs/assembly/verify-motion.cjs
node docs/assembly/verify-arrow-effects.cjs
```

ブラウザー確認だけは既存のPlaywrightとFirefoxを使う。
`PLAYWRIGHT_MODULE` と `FIREFOX_PATH` で配置を指定できる。
ローカルHTTPで試す場合:

```sh
uv run --locked python -m http.server 8765 --bind 127.0.0.1 --directory docs
```

その後 `http://127.0.0.1:8765/assembly.html` を開く。
外部スクリプト、CDN、フォント取得、ビルド時のネットワーク接続は不要。

| ファイル | 役割 |
|---|---|
| `engine.js` | 格子・回転・全共有面の判定、親の認識、案内配置、履歴 |
| `app.js` | 操作と状態の接続、Canvasの描画、比較図、親子の閲覧 |
| `motion.js` | 表示専用の離脱・剛体回転・接近の補間 |
| `i18n.js` | 共通の翻訳処理と画面テンプレートの接続 |
| `../locales/*.json`, `../site-language.js` | 言語別の翻訳、表示方向、値の差し込み、言語設定と保存 |
| `guide.html` | 図付きの短い操作ガイド。各言語の訳文を翻訳辞書に収録し、同じHTMLに内蔵 |
| `demo.js` | 独立画面での実操作デモ、カーソル、再生・停止・一手送り |
| `page.html`, `style.css` | 画面とレスポンシブ配置 |
| `../build-assembly.cjs` | 既存証明書の面情報・子配置とソースを一つのHTMLに埋め込む |

生成元は既存の `strong/audit/motif_grouping_certificate.json`。
生成HTMLには候補のハッシュと証明書ファイルのSHA-256を含める。
元の研究データ、曲面、凍結済みの成果物は変更しない。

### 言語を追加するには

[翻訳ファイルの案内](../locales/README.md)に従い、`../locales/` に言語別JSONを追加して再生成する。
対応言語一覧と選択肢は自動生成される。`{count}` などの差し込み名は維持し、
全メッセージを翻訳する。欠けたキーや差し込み名の不一致はビルド時に検出する。
初期言語はURL、保存設定、ブラウザー設定、英語の順で選ぶ。
`?lang=ja` / `en` / `zh` と `?demo=1` を使用できる。
トップページと表示言語を共有し、保存領域が使えない場合もURLで引き継ぐ。
履歴内部の操作名と判定ロジックは翻訳せず、表示するときに言語を適用する。
残り5言語の翻訳は `../locales/inactive/` に保存し、通常のビルド・検証対象には含めない。
RTL表示の仕組みは残すが、休止言語を再開するときは訳文補完と表示の再検証を行う。
翻訳とデモはHTMLに内蔵され、外部サービスへの接続は不要。

デモ画面はビルド時に同じアプリをもう一つ内蔵し、`iframe.srcdoc` で開く。
実演用の操作窓口はその画面だけで有効になり、通常の組立には追加しない。
面・ボタンの実際の画面座標を求めてクリックするため、固定ピクセル位置の録画には依存しない。
保存済み設計の面 `0:11` と部品の面 `20` を使い、右90度回転で適合する例を実演する。
デモの入れ子は生成せず、外部ファイル取得も不要。

[仕様書](../INTERACTIVE_ASSEMBLY_SPEC.md)に対する、今回の試作の主な簡略化:

- 曲面の凹凸を省いたchairと模様・矢印を表示する。形状による物理接着や組立経路はシミュレートしない。
- 面選択は3Dのクリックを基本とし、候補一覧も補助として残す。仕様の小さな位置図付きカードは未実装。
- 親への三段階はボタンで切り替える。連続変形アニメーションは使っていない。
- 内部を掘り下げると各部品自身の座標で表示する。全階層を同時描画する表示は未実装。
- 接触不適合の説明はあるが、周辺の行き詰まり証拠の再生、任意の古い子の取り外し、永続保存は未実装。

材料8個は試作の作業単位であり、自由組立で親ができなくても誤答とは扱わない。
次は初見のプレイヤーで、候補が探せるか、比較図から回転方向が分かるか、
Undoと閲覧からの復帰が自然か、材料切れが探索を妨げないかを確かめる。
