3. 比較窓で、模様と矢印を合わせる

「接触面を比べる」は、両面を同じ向きから見た図です。左の矢印を右向きとして、右の矢印を下の例に合わせます。

A →＋A ↑✓
B →＋C ←✓
C →＋B ←✓

比較窓の下の「この図で左へ90°」「この図で右へ90°」で、部品の向きを変えられます。

接着できないときは、別の面や向きも試しましょう。重なりがなく、触れるすべての面が合う必要があります。「なぜ？」で理由を確認できます。

4. 接着して、次の1個へ

条件がそろうと「接着する」を押せます。押すまでは仮置きです。接着した部品は組立と一体になります。

接着する→次の1個

やり直したいときは「元に戻す」。接着直前の部品に戻せます。「親を一つ作る」では、「ヒントを見る」を押すと、場所・矢印・具体的な候補の順に案内します。

1個できたら、次は？

「親を一つ作る」では、ヒントを使って8個の組立を目指せます。決まった形ができたら「親にまとめる」、続いて「この親で次を組む」で、ひと回り大きな組立に進めます。「自由に組む」では、別の組み合わせも試せます。

一つを決めると、どこまで決まる？

線で結ばれた2か所は、同じ深さの突起とくぼみになります。条件を1本ずつ加えてみてください。

線の表示は説明用です。設計の深さを変えるのは次の段階です。

点は実際のポート、線は置換が要求する接着条件です。位置は見やすく並べ替えています。

この図は、独立した群のうち一つを表示しています。線でつながった群には、深さを決めるつまみが一つ残ります。

深さは一つに決まらなくても、接着相手は決まる

群を選んでつまみを動かすと、その群の突起とくぼみが一緒に変わります。別の群と同じ深さになると、接着相手が増えることがあります。

6種類の例では、一部の群の突起とくぼみも反転します。深さの種類が減っても、面全体の判定が同じになる例です。

小さいルールと、大きいルールを比べる

同じ相対配置について、子1個同士と、8個をまとめた親同士の接着を比較します。

候補を選ぶと、その候補の元の深さに戻ります。配置数は、固定した分割での子の向きの選び方です。

親だけが接着できるなら、まとめることで禁止条件が失われています。両方向で同じ接触が許されるとき、接着規則は粗視化の不動点です。

「唯一」といえる範囲

固定した8個への分割とポート位置で、各階層に同じ子の向きを使う6,561配置を調べた記録です。独立した群を別の深さで区別すると3種類のパターンになり、その代表のうち同じ接触規則に戻るのは候補1です。任意の形状や、群をまとめた全設計の唯一性は示していません。
