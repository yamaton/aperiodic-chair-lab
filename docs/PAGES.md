# Tutorial project site

The public reading edition lives at
<https://tritonlab.io/aperiodic-chair-lab/>:

- `tutorial/`: illustrated tutorial, contents and figure enlargement.
- `viewer/`: interactive curved-chair viewer.
- `downloads/tutorial.html`: a self-contained download for offline reading.
- `build.json`: source commit, tutorial source hash, output hashes and checks.

This is a GitHub Pages **project site** for `yamaton/aperiodic-chair-lab`.
It inherits `tritonlab.io` from the existing `yamaton.github.io` user site.
No user-site files, DNS records or root-domain configuration are changed.
The project does not install a `CNAME` file or claim the root URL.

## Build locally

From the repository root, with Node.js and Pandoc **3.11** installed:

```sh
node docs/build-site.mjs
```

`PANDOC` can select a specific executable. `SITE_URL` can override the
default project URL; CI obtains the effective URL from `configure-pages`.
The output is `_site/`, ignored by Git. The builder embeds figures, styles,
MathML and enlargement controls, checks site links and anchors, and writes
the manifest. No Python environment or Lean build is needed to publish
already generated teaching assets.

The tutorial's authoritative text remains `APERIODIC_CHAIR_TUTORIAL.md`.
`pages-links.lua` rewrites research links to GitHub at the source commit
used by the build. The online tutorial links to the hosted viewer; the
download uses its absolute URL. Following references requires a connection,
but reading text, formulas and figures in the download does not.
The viewer's deployment copy receives project navigation and corrected
research links. The original standalone viewer and repository HTML edition
are preserved without modification.

Optional Firefox verification, using an existing Playwright installation:

```sh
node docs/verify-pages.cjs
node docs/verify-pages.cjs https://tritonlab.io/aperiodic-chair-lab/ /tmp/pages-live.json
```

Set `PLAYWRIGHT_MODULE` and `FIREFOX_PATH` for installations other than the
script's defaults. The local check serves `_site/` under the project
subpath, then checks desktop/mobile layout, figure keyboard controls,
navigation, viewer controls, output hashes and the actual HTML download
with networking disabled. This verifies presentation, not mathematics.

## Deployment

Repository Settings → Pages uses **GitHub Actions**, with HTTPS enforced.
`.github/workflows/pages.yml` builds and deploys on changes to tutorial
source, styles, controls, figures, the viewer or the site build machinery
on `main`. It also supports manual `workflow_dispatch`. Documentation-only
deployment records do not trigger another build.

The workflow pins action commits and verifies the pinned Pandoc package's
SHA-256 before installation. It uploads only `_site/`, then deploys with
the `github-pages` environment and Pages/OIDC permissions. It does not
upload the repository root as a website. Research notes and evidence are
still available through their GitHub links.

To regenerate diagrams or the original repository HTML edition, use the
separate commands in [the project index](INDEX.md#undergraduate-tutorial).
Mathematical evidence and frozen artifacts are not regenerated by deployment.
