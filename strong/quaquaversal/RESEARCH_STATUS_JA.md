# Quaquaversal matching rules：Q032時点の整理

ユーザーの「次ひと段落したら、いったん整理」という依頼に合わせ、
Q032の計算・検証・記録を終えたところで探索を一時停止した。
再開用のデータは保存済みで、計算中のプロセスはない。

## 現在の結論

**目的の aperiodic monotile は、まだ得られていない。**
現在有望なのは、面だけでなく辺・頂点で触れるタイルも含めた
「周囲の配置全体」を制限する、6,840種類の近傍からなるルールである。
これは近傍の種類数であり、6,840種類のタイルを作ったという意味ではない。
また、この近傍ルールを一種類の立体の凹凸や面の模様に実装したわけでもない。

このルールに従う無限タイリングの存在と、任意の合法タイリングを
**二段階まで一意に親タイルへまとめること**について、記述した論証と
正確な有理数計算による有限検証がある。外部の数学者による査読や
Leanによる形式検証を受けた結果ではない。

主な未解決点は、親にまとめたあとも同じルールが成立するかどうか。
これが示せれば階層化を何段階でも繰り返せる。現状の二段階だけでは、
非周期性も、目標とする「すべての合法タイリングの対称群が有限」も導けない。

## 何が分かり、何が失敗したか

| 試み | 結果と意味 |
|---|---|
| 三角柱8個による相似な親の構成 | 配置と被覆を正確に再構成。置換でタイリングを作れることと、ルールがその置換を強制することは別問題。 |
| 一種類の点ごとの面装飾、指定した反転配置の族 | 扱ったモデルでは周期タイリングの反例が残った。256通りの固定した反転配置についても、等値・実数符号反転の装飾モデルを検査。任意のmatching rule全般の不可能性ではない。 |
| 接触する2枚の相対配置や、面で接する近傍の制限 | 明示的な周期反例が残った。 |
| 辺・頂点接触を含む6,840種類の完全近傍 | 既知の周期反例の系列を排除し、一段階の親分解を認識できた。すべての周期タイリングを排除したわけではない。 |
| 親分解後の余分な近傍の排除 | 当初9,357件あった候補を、必要条件の検証で82件まで減らした。 |
| 余分な近傍も許した拡張ルールの親分解 | 7,000種類の拡張ルールでも一段階の分解を確認。これにより元のルールについて二段階の分解が得られる。 |
| 8個の兄弟タイル間の制約（Q031） | 対象160件すべてに有限制約を満たす組が残り、追加排除はゼロ。実際の無限タイリングの存在を示すものではない。 |
| 親側の近傍を一層広げる（Q032、今回） | 82件すべて残った。候補集合を15,782回縮小したが、親近傍を丸ごと排除するには至らなかった。 |

**残り82件は「82個のmonotile候補」ではない。**
現在検討している近傍ルールについて、親へまとめたときに出現するかも
しれない、元の6,840種類に含まれない局所配置である。
有限の必要条件を通過しただけで、実際に出現できるかは未確定。
これらをすべて排除するのが、同じルールでの再帰的な階層化を示す一つの道になる。
別の道として、余分な近傍を含む拡張ルール自身の再帰的な階層化を証明する余地もある。

## 今回の一区切りと検証

Q032では、親タイルの座標とルールを明示した入力を新設した。
細かいタイル側の座標番号との混同を避け、82件すべてについて近傍を
一層広げた。別の検証スクリプトで次を再計算した。

- 入力変換：82件、3,572個の初期候補集合、使用する1,291組の逆相対配置。
- 必須の近隣タイルを追加する処理：140,525回の候補集合の共通部分と、36,676通りの配置。
- 追加後のタイル間の制約伝播：15,782回の候補集合縮小と、6,850通りの幾何学的な関係。

追加で排除できた親近傍はゼロ。この不成功も保存した。
再現手順は136コマンドになった。最初の18コマンドは連続再実行済み、
その後の追加コマンドは各々実行・検証済みである。
**136コマンド全体の最初からの連続再実行は、まだ行っていない。**
`--audit-only` は保存された入力ハッシュと期待結果の検査であり、
幾何計算や探索そのものの再実行ではない。
今回の保存状態では962件の入力ハッシュ検査が通り、再開データの
全82件・4,648個の配置が検証済みの出力と一致することも確認した。

## 再開時の選択肢

1. **親側の近傍をさらに広げる。** 今回の続きから計算できる。
   次の一層で82件が減る保証はなく、まだ実行していない。
2. **推定した親同士の内部重複を制約に加える。** 二段階の分解を利用し、
   局所的には許された組でも、親同士が重なるなら排除するという案。
   未実装であり、正確な重複証拠と別の検証が必要。
3. **階層情報を明示する別のルールを構成する。** 複数の装飾種類を使う
   中間構成を含め、辺・頂点に情報を運ぶ方式を検討する。
   一種類の立体への実装と区別して扱う。
