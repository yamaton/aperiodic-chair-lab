Aperiodic geometry / a concrete construction

One solid. An endlessly turning stack.

The Schmitt–Conway–Danzer biprism fills three-dimensional space using identical blocks. Its crossed ridges turn successive layers through an irrational fraction of a full revolution.

Why it fills space

Each layer has complementary ridge and valley surfaces. Turning and raising the next layer matches the entire interface exactly. With separation set to zero, the blocks meet without interior overlaps.

Why translation fails

The angle is θ = arccos(1/3). No integer number of layers restores an orientation. A horizontal translation would have to belong to every rotated layer lattice; their infinite intersection contains only zero.

What is still allowed

A combined turn and rise can repeat the stack. This is aperiodicity with respect to translations, rather than strong aperiodicity. The solid uses one handedness; allowing mirror-image blocks changes the claim.

Finite patches illustrate the infinite construction; the straight outer edges are patch boundaries. The 60° control changes the block itself.
